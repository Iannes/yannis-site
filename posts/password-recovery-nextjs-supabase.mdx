## Password Recovery with Next.js 14 and Supabase

In this post, we’ll walk through how to implement a password recovery system using Next.js 14 and Supabase. We'll cover setting up an API route to handle the password reset link, and client-side pages for users to request a password reset and set a new password.

### Step 1: Configure Supabase Client

Ensure you have the Supabase client set up. We’ll use it in our API routes and client-side code.

```typescript
// lib/supabase/server.ts
import { createClient as createSupabaseClient } from '@supabase/supabase-js';

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const supabaseKey = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!;

export const createClient = () => createSupabaseClient(supabaseUrl, supabaseKey);
```

### Step 2: Create the Password Reset Confirmation API Route

This API route will handle the confirmation link sent to the user’s email. It verifies the token and redirects the user to the password reset page.

```typescript
// pages/api/auth/confirm.ts
import { NextResponse } from "next/server";
import { createClient } from "@/lib/supabase/server";
import { absoluteUrl } from "@/lib/utils/absoluteUrl";
import { Routes } from "@/types";

export async function GET(req: Request) {
  const supabase = createClient();
  const url = new URL(req.url);

  const token_hash = url.searchParams.get("token_hash");
  const type = url.searchParams.get("type");

  if (!token_hash || type !== "email") {
    return NextResponse.json({ error: "Invalid request" }, { status: 400 });
  }

  const {
    data: { session },
    error,
  } = await supabase.auth.verifyOtp({ token_hash, type });

  if (error) {
    return NextResponse.json({ error: error.message }, { status: 400 });
  }

  // Redirect to the specified URL or a default page
  return NextResponse.redirect(absoluteUrl(Routes.passwordReset));
}
```

### Step 3: Set Up the Email Template in Supabase

In the Supabase Dashboard, navigate to the "Authentication" settings and configure the reset password email template to point to your confirmation endpoint:

```
{{ .SiteURL }}/api/auth/confirm?token_hash={{ .TokenHash }}&type=email&redirectUrl={{ .RedirectTo }}
```

### Step 4: Password Reset Client-Side Implementation

Create a page where users can set their new password. This page will be linked from the password reset email.

```typescript
// pages/reset-password.tsx
"use client";
import { usePasswordReset } from "@/lib/hooks/usePasswordReset";
import { Input } from "@/components/ui/input";
import { Button } from "@/components/ui/button";
import { toast } from "sonner";
import { supabase } from "@/lib/supabase/pkce";

import { Routes } from "@/types";

export const PasswordReset = () => {
  const { newPassword, setNewPassword } = usePasswordReset();

  const handleSetPassword = async (e: React.FormEvent) => {
    e.preventDefault();
    const { error } = await supabase.auth.updateUser({
      password: newPassword,
    });
    if (error) {
      toast.error("We couldn't change your password. Please try again.");
    } else {
      toast.success("Password updated successfully!");
      window.location.href = Routes.home;
    }
  };

  return (
    <form onSubmit={handleSetPassword} className="flex flex-col gap-4 mx-auto">
      <Input
        type="password"
        placeholder="New Password"
        value={newPassword}
        onChange={(e) => setNewPassword(e.target.value)}
        required
      />
      <Button type="submit">Reset Password</Button>
    </form>
  );
};

export default PasswordReset;
```

### Step 6: Client-Side Code for Requesting Password Reset

This page will allow users to input their email address and request a password reset. Supabase will then send an email with the reset link.

```typescript
// pages/forgot-password.tsx
"use client";
import { useState } from 'react';
import { supabase } from '@/lib/supabase/client';
import { Input } from '@/components/ui/input';
import { Button } from '@/components/ui/button';
import { toast } from 'sonner';
import { Routes } from '@/types';

const ForgotPassword = () => {
  const [email, setEmail] = useState('');
  const [loading, setLoading] = useState(false);

  const handleResetPassword = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);

    const { error } = await supabase.auth.api.resetPasswordForEmail(email, {
      redirectTo: `${window.location.origin}${Routes.passwordReset}`,
    });

    setLoading(false);

    if (error) {
      toast.error("Error sending password reset email");
    } else {
      toast.success("Password reset email sent");
    }
  };

  return (
    <form onSubmit={handleResetPassword} className="flex flex-col gap-4 mx-auto">
      <h1 className="text-xl font-bold">Reset Password</h1>
      <Input
        type="email"
        placeholder="Enter your email"
        value={email}
        onChange={(e) => setEmail(e.target.value)}
        required
      />
      <Button type="submit" disabled={loading}>
        {loading ? 'Sending...' : 'Send Reset Email'}
      </Button>
    </form>
  );
};

export default ForgotPassword;
```
